# 九九寶石 (Nine-Nine Gems)

給小朋友練習九九乘法的寶石消除遊戲：消寶石得分、遇到題目寶石要回答乘法題、
熟練某個數字的乘法就能學會對應的寶可夢主題技能。

🎮 線上試玩：https://tom.ky/9x9_game/ （push 到 `main` 會自動由 GitHub Actions 部署）

## 開發

```bash
npm install
npm run dev       # http://localhost:5173
npm test          # vitest（純邏輯單元測試）
npm run build     # 產出 dist/（相對路徑，可直接放 GitHub Pages 或任何靜態主機）
npm run preview
```

## 玩法摘要

- 8×8 盤面，交換相鄰寶石成三消除；4 連 → 直線寶石、L/T 形 → 炸彈、5 連 → 彩虹。
- **題目寶石**（帶 `a×b` 徽章）被消除時要作答：答對加分並回復技能 PP，答錯該格變成石頭。
- 每關要在步數內 **達到目標分數且清除所有障礙**。
- Level 1 只有 2 的乘法，每過一關多加一個數字，Level 8 起 2～9 全開；第 9 關起改用數字鍵盤作答（可在設定改）。
- **熟練**某個數字 = 該數字的 8 個組合都答對過 **且** 連續答對 5 題 → 永久解鎖技能。

| 數字 | 技能 | 對應障礙 |
|---|---|---|
| 2 | 居合斬 | 🌳 小樹 |
| 3 | 碎岩 | 🪨 石頭 |
| 4 | 閃光 | ❓ 黑暗（＋下一題提示） |
| 5 | 怪力 | 🗿 大岩石（只有怪力 / 十萬伏特能移除） |
| 6 | 衝浪 | 💧 水窪（整列） |
| 7 | 火焰放射 | 🧊 冰塊（整行） |
| 8 | 暴風雪 | 清除全盤同色 |
| 9 | 十萬伏特 | 3×3 內所有寶石與障礙 |

## 程式結構

- `src/core/` 純邏輯（無 DOM）：盤面、成三、特殊寶石、障礙、出題、關卡公式、技能、熟練度、存檔、狀態機。
- `src/render/` Canvas 繪製與補間動畫。
- `src/ui/` DOM HUD、答題視窗、各畫面、輸入、音效。
- `src/i18n/zh-TW.ts` 所有文字。
- `tests/` vitest 單元測試。

進度存在 `localStorage`（key：`nine-nine-gem-save-v1`）。
